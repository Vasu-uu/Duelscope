# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Welcome newcomers, assume good faith, and give feedback on the work, not the person.

Unacceptable behaviour includes harassment, personal attacks, discriminatory language, publishing others' private information, and any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove comments, commits, or contributors that violate this code. Report problems by opening a confidential issue or contacting the maintainer through the GitHub profile at https://github.com/Vasu-uu.
